# ADR-0004 搜索与富文本内容安全

- 状态：已接受
- 日期：2026-09-01

## 背景

浏览端需对标题、摘要、正文进行文本检索；管理端使用富文本编辑器，需防止 XSS 并能清洗入库内容。中文内容对分词组件不敏感，需权衡组件引入成本。

## 决策

- 搜索：PostgreSQL `pg_trgm` + GIN 索引，对 title/summary/body_text 做大小写不敏感匹配；结果仅限已发布内容。全文检索引擎（如 Meilisearch）作为后续增强项，不进入当前交付。
- 富文本：编辑器（Tiptap/ProseMirror）在前端仅暴露白名单内工具栏；后端以 HTML 白名单消毒为唯一权威（剥离 script/style 与事件属性），并同步生成纯文本字段供搜索。
- 输入限制：请求体严格模式（拒绝未知字段），正文大小与各字段长度上限见接口契约。

## 影响

- 零额外检索组件即可满足当前检索需求；后续切换全文检索引擎不影响数据模型。
- XSS 防线分层：前端工具栏受限 + 后端权威消毒，且入库即为清洗后内容。
